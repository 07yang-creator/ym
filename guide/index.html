CONCEPT

1 · 设计思路

把项目管理藏进日常动作

没有甘特图，没有依赖关系，没有 WBS。一场活动 = 一页台本，台本的每一行挂着这一环节要用的 人 / 物 / 钱。你排台本的时候，任务清单就已经建好了 —— 不用再单独维护一份。

计划随时改，任务自动跟上

活动是活的：场地临时换、有人退出、临时加一个环节、日期往后挪。 这套系统的任务清单不是另存的一份 —— 台本上那张牌本身就是任务。 所以你在计划页上改什么，执行看板下一秒就是改完的样子：

你在计划页做的事执行看板上自动发生的
加一个环节 / 挂一个人 / 加一件要做的事看板上多出一件待办
删掉一行 / 拿掉一张牌对应的任务跟着消失，也不再催你
换负责人 · 改日期 · 调时长 · 设截止它在时间轴上的位置和提醒自己跟着走
点一下牌翻状态任务当场在树上换边（进行中 → 完成）
永远只有一份清单 不存在「计划改了、任务表忘了改」这种事，也不会出现两份对不上的进度。 按下「开始跟踪执行」之后计划照样随便改，跟踪不会重来 —— 所以你可以一边办一边调整，而看板上显示的进展始终是真实的那一份。

全程 AI 辅助，但 AI 只提议

在哪AI 做什么
票据 📷拍一张領収書，自动读出金额、店名、日期、勘定科目、登録番号（T+13 位）
名单 📷群聊截图直接读出报名者姓名（只读名字，不抄聊天内容，不猜性别）
报名表 📷纸质报名表拍照 → 自动填进嘉宾资料卡
语音 🎤每个输入框旁边都有话筒，说话代替打字
补写 ✨环节说明、复盘小结写不出来时，点一下让 AI 起个头
铁律：AI 提议，人确认 识别结果一律先变成一张可以逐格改的确认卡，你点「确认」它才落账。任何情况下系统都不会自动记账。

自学习：越用越聪明

每办完一场，复盘页点一次 「保存回资产库」：这场的台本变成模板、新加的环节变成灵感、 帮过忙的人进人员库、实际价格更新收支项。下一场就是从这些东西开始，而不是从空白开始。 办得越多，铺一场新活动越快。

对内对外，一条记录追到底

志愿者的工时和贡献、嘉宾的报名和到场、捐赠者交来的票据、每一笔收支的原始凭证 —— 都挂在同一棵树上，从计划一直连到复盘和总账。

手机端优先

所有界面都是先按手机排的。活动当天你拿着手机就能签到、记时间、拍票据； 只有执行看板（时间树）和总账在电脑上信息更密一些。

CORE

2 · 核心界面：计划 → 执行

整套系统只有两个真正的核心页面：计划页（把人、物、钱部署到台本上）和 执行看板（一览所有事情的状态，点一下翻转）。其余页面都是围着这两个转。

2.1 计划页 —— 任务与资源部署

往台本上加东西的三种方式：

  1. 从资产库点 — 左侧「资产库」按钮打开面板，点一个模板铺满整份台本，点一个灵感插一行环节，点一个人 / 物 / 收支项挂成胶囊。
  2. 直接写 — 在行上直接输入新名字，系统自动建记录。
  3. 说 — 点输入框旁边的 🎤，说话转文字。

2.2 执行看板 —— 一览与状态翻转

计划页点 「计划好了 · 开始跟踪执行」，这场活动就进入执行阶段，进入时间树：

状态怎么翻

资源（人 / 物）有四个状态，事项有三个状态，在看板上统一成三段显示：

资源胶囊（人 / 物）看板上的位置意思
未联系待办（顶上）还没开口问
已联系 · 已确认进行中（右侧）问了 / 对方答应了，东西还没到位
到位完成（左侧）人来了 / 东西拿到了 —— 这一件不用再管

翻转有两种点法：在计划页直接点胶囊循环切换，或者在看板上点开这张卡选一段。 一件事做完，它会在它完成的那一天从右边滑到左边 —— 树的左半边就是「什么时候做完了什么」的记录。

随时回去改计划

开始跟踪之后，计划页不会被锁上。两个入口随时来回走：

  • 计划页顶上变成 ● 执行跟踪中，旁边一个 ▶ 执行看板 按钮 —— 台本照样可以增删改。
  • 执行看板底部有 ✎ 调整计划，一点就回到计划页。
  • 活动当天也一样 —— 「当天」页左上角的 ← 计划 一步就回得去， 顺序、时长现场随便调（见 §3 阶段三）。

看板底部另外两个按钮是 ✓ 完成活动 和 取消活动 —— 只有这两个才会改变活动的阶段， 改计划不会。

截止日期只提醒，不排期 给一件事设截止后，它会被钉在树干上那一天，临近变黄、过期变红并浮到最上面，还能一键 📤 催办。 但系统永远不会因为一个截止去改活动日期或挡住别的事 —— 排期是你的判断，不是软件的。
WORKFLOW

3 · 主办工作流程（四个阶段）

你完整的一圈是：构思 → 策划 → 任务 → 资源 → 发布 → 领任务 → 追踪 → 完成 → 更新 → 复盘。 在界面上，这一圈落在四个阶段里：

PHASE 1
策划

构思 → 铺台本 → 挂人物钱。在计划页完成。

PHASE 2
筹备

派活 → 发布 → 领任务 → 追踪催办 → 收报名。在执行看板完成。

PHASE 3
当日

签到 → 跑台本 → 记实际时间 → 现场记账，顺序和时长随时改。在当天页完成。

PHASE 4
复盘

对账 → 记工时评价 → 写小结 → 保存回资产库 → 再办一场。

工作台上每张活动卡下面的四个胶囊 计划 报名 当天 复盘 就是这四个阶段的入口，随时可以来回跳。

阶段一 · 策划

  1. 新建活动 — 工作台点「＋ 新活动」，或者在资产库点一个模板直接铺满整份台本。
  2. 填活动信息 — 名称、副题、日期、时间、场地、名额。
  3. 排环节 — 每行填时间、环节名、负责人；说明写不出来点 ✨ 让 AI 起个头。环节可以拖动排序，时刻会自动往下顺延。
  4. 挂资源和钱 — 从资产库点人、点物资、点收支项，挂到对应的环节上；全场性的东西（场地、门票、保险）挂在最上面的活动信息卡上。
  5. 加要做的事 — 点「＋事项」加上打电话确认场地、印名牌这类杂事，它们也会进执行看板。

阶段二 · 筹备

  1. 开始跟踪执行 — 计划页点「计划好了 · 开始跟踪执行」，计划就变成会自己提醒你的执行看板。 之后计划照样随便改，跟踪不会重来（见 §2.2）。
  2. 派活 — 在执行看板点开一件事，写上负责人（从名册选或直接写名字）、设难度、设截止。
  3. 发布没人认领的 — 看板顶部有「一键发布 N 项没人认领的」，发出去让志愿者自己抢。
  4. 追踪与催办 — 每天打开看板看「今天」这一横线：上面是已经过去的，下面是还剩的天数。过期的事会自己浮到最上面变红，点 📤 催办一键发提醒。
  5. 收报名 — 活动卡上的「报名」胶囊进报名页（详见 §8 嘉宾管理）。

阶段三 · 当日

活动卡上点「当天」，三个标签页：看板 · 台本 · 记录。

当天照样能改顺序和时长 —— 这条对现场最要紧

现场永远不按计划走：上一个环节拖了、嘉宾还没到齐、临时想把茶歇提前。 台本不是活动当天就冻结的东西：

要改什么在哪改改完发生什么
时长就在「当天 → 台本」这一页，直接改那一行的「分」 后面每一行的时刻和顶上的「预计结束」立刻自动顺延
顺序点左上角 ← 计划 回计划页，按住 ⠿ 拖，或点 ▲ ▼ 回到「当天」，台本已经是新顺序，时刻也已经重排好 —— 两边本来就是同一份， 不用保存、不用同步
加 / 删环节同上，在计划页加行删行 当天台本和执行看板同时跟着变
顺序一改，时刻自己重排 —— 你不用管 第一次调顺序时，系统会把你手填的时刻换算成时长，并提示一句 「时刻已改成按时长自动顺延」。换算的那一刻，屏幕上的时刻一个都不会变； 变的是从此以后 —— 每个环节带着自己的长度走。
举个例：把 20 分钟的茶歇提到 30 分钟的快问快答前面，两段各自按自己的长度排， 后面的环节自动往前挪 10 分钟，时刻永远是升序的，不会串位。
整场的开始时刻留在第一行：就算你把第一个环节换掉，台本还是从原来那个点开始。 想把某一段钉在某个时刻（比如场地只能 15:30 进），随时在那一行重新填一个时刻 —— 它就是新的锚点，从那里往下重新排。下次再调顺序时它会同样被换算成时长（时刻照样不变）， 所以「钉」是当下有效，不是永久锁定。

已经点过的实际开始时间不受影响；计划时刻也不会被改掉 —— 复盘页那份「计划 → 实际」的对照，看的就是这两者的差距。

当天要记账，用页面上的 📷 拍票据，或者顶部「记一张票据」。记录标签页放的是当天临时的记录和附件。

阶段四 · 复盘

复盘页还能导出：台本打印 / 分享、收支 CSV、名单·评价 CSV。忘了记的票据用「补一张票据」补录。

LIBRARY

4 · 模板与资源库 · 人员注册

资产库有五个标签，每办一场就长一点。这是整套系统「自学习」的地方 —— 它不是设置页，是你的积累。

任务模板怎么来的 你不用单独维护任务模板。台本里每个环节挂的「事项」会跟着台本一起被保存回模板 —— 下次用同一个环节，同样的事项自动重新出现（已搁置的不会跟来，状态会重置）。

人员注册：发一串邀请码就行

你不需要知道对方的邮箱。你发码，TA 自己注册，邮箱和密码由 TA 自己填。

  1. 你 — 资产库 → 人员 → 点一个人 → 🔑 → 生成邀请码 → 发送给 TA。
  2. TA — 打开 ym.jjconnect.tokyo/member/，点「我有邀请码，还没注册」， 输入邀请码 + 自己的邮箱 + 自设密码。
  3. 完成 — 邀请码当场作废，用户编码永久留在 TA 的记录上，并自动归到你名下。 以后 TA 用邮箱 + 密码登录。

用户编码：位数就是身份

编码身份谁能发
H001主办者只有平台管理员
V0014志愿者你
V0014N有偿服务者（拿报酬的）你
P482719嘉宾（6 位随机）你
D0007捐赠者你
O003记者 / 旁观你
嘉宾编码为什么是随机的 其他身份按顺序编号，嘉宾故意用 6 位随机数 —— 顺序号会泄露「这家一共来过多少嘉宾」 和「这个人大概什么时候来的」，对相亲活动的参加者是真实的隐私。
邀请码只发给 TA 本人 拿到这串码的人就能用它注册成对应身份。不要发到群里。码只显示这一次； 发漏了用「重发邀请码」拿新的（旧的立刻作废，编号不变）。

物资和账务登记

物资在资产库 → 物资；账务（收支项）在资产库 → 收支项。 物资分消耗品和可存续品两类，消耗品才有类别 / 保存期限 / 价值 / 已使用这些字段。 库存状态见 §6 捐助管理。

VOLUNTEER

5 · 志愿者系统

两种派活方式

怎么做什么时候用
直接指定在执行看板点开一件事，填负责人大部分情况
发布抢单看板上点「一键发布 N 项没人认领的」你也不知道该派给谁的时候

发布出去的任务会出现在志愿者各自的页面上（没有公共看板），先点先得 —— 第一个点「接任务」的人拿到，后点的人看到「该任务已经被领取」，而且看不到是谁领走的。 赢的人还要等你点一次「确认指派」才真正归 TA。

难度与星级

每件事可以点选难度 C · B · A · S · SS（默认 C）；每个志愿者有一个你授予的星级。 难度高于本人星级的任务接不了 —— 界面上照样显示，但锁着（🔒 需 S 级）。 藏起来只会让人以为没任务，锁住才有升级的动力。

交任务 → 确认 / 退回

  1. TA 交 — 志愿者在自己那条任务上填工时 / 自费 / 简短说明，可以传票据和附件，然后点「交任务」。
  2. 卡片左移显示「交付」 — 虚线，区别于实线的「完成」。这只是投影：真正的状态还没变。
  3. 你确认 — 打开看到工时、自费、说明、票据 → 点「确认完成」，状态才翻到完成。
  4. 或者退回 — 点「退回」并必须写清楚原因。TA 那边显示「该任务未被确认，需要您跟进」，点开看你的反馈，改好再交一次。

贡献与等级

志愿者在自己页面底部能看到：完成件数 · 累计工时 · 累计自费 · 主办的感谢 · 服务经历。 数据来自你已确认的交付，加上你在复盘里登记的工时。

工时不重复计算 本人申报（TA 自己交任务时填的、你确认过的数字）和主办登记（你在复盘里填的） 分开显示、不相加。TA 在自己页面上两个都看得到。
自费不进收支，也不进总账 志愿者自己掏钱买的东西，是贡献记录，不是你的账目 —— 它不参与活动差额，不进总账，也不出现在任何导出的 CSV 里。 需要你报销的，在票据确认卡上选「主办报销」。
DONATION

6 · 捐助管理

登记捐赠人

捐赠票据入账

捐赠人的写入面是最小的 捐赠者只能交票据，看不到任务、看不到名册、看不到别人。这一块空着的时候也会露一行， 告诉你差哪一步（比如「捐赠人还没有账号」）。

物资入库 · 库存 · 消耗

物资的库存就是一颗胶囊、四个状态，点一下循环切换 —— 不是一套进销存：

待入库 → 已入库 → 已发放 → 已用完

状态在资产库 → 物资的列表上直接点（见上面 §4 的物资截图），也在物资资料卡里。 捐赠来的物资就是登记成一条物资记录，关联到捐赠人。

MONEY

7 · 收入 / 开支管理

目前只记账，不收款 系统不代收门票、不处理支付。门票金额、报名费都只是记录，钱怎么收由你线下决定。 在线收费属于规划中的功能。

记一张票据：拍照 → 识别 → 确认

能拍票据的地方：

  • 工作台顶部「记一张票据」—— 随时录入，会当面问你「这笔算在哪」
  • 计划页的收支胶囊 —— 已经知道算在哪场、哪一项
  • 执行看板点开任务 → 票据 —— 凭证挂在这件事下面
  • 复盘页「补一张票据」—— 事后补录
  • 志愿者 / 捐赠者交来的 —— 你点「入账」转成正式账目
在电脑上也能「手机拍」 票在手里、相机在手机上。工作台点「手机拍」 → 出现二维码 → 手机扫（不用登录）→ 拍 → 自动传回电脑弹出确认卡。可以连着拍，一张一张确认；二维码 10 分钟过期。

总账

几条要记住的规矩

规矩为什么
金额一律按税込记税务判断交给税理士。系统不猜税率 —— 票面上读不到的就空着，绝不推算。
取消不删行记错了在总账里点「取消」并写理由，行会留着划掉。删掉的账是查不回来的。
「要核对」标记识别服务没响应、或者没写勘定科目的行会打上这个标记。清完再导出。
未決済单列振込 / クレジット 没填决済日的，作为未払 / 未収另外列出来。
门票只记一次已经单独交过报名费的人，不会再被门票汇总算一遍。
原件存在你自己的网盘 票据原图上传到沙龙自己的 Google Drive（按「活动 · 日期 / 票据·报名表·名单·附件」分文件夹）， 系统只存链接。拍错的票据请到 Drive 里手动删 —— 系统没有删除权限，这是有意的。
GUEST

8 · 嘉宾管理

邀请码与嘉宾一一对应

做法和 §4 人员注册 完全一样：你在名册里建一条嘉宾记录 → 发一串邀请码 → TA 自己注册。 注册成功后这个账号就和名册里那条记录绑定，编码 P + 6 位随机数。

嘉宾能看到什么、能做什么

看得到看不到
公开活动信息自己的资料卡（职业 / 年龄 / 联系方式 / 评价 / 择偶条件）
当天流程（只有时间和环节名）环节说明（那是给志愿者的操作指示）
自己的号牌其他任何嘉宾、任何志愿者
主办方通知钱、名册、评价
嘉宾不需要提交隐私资料 嘉宾账号不是一个「查看我自己的档案」的窗口 —— TA 注册只需要邮箱和密码。 资料是你填、只有你看得到的。系统不替你管理嘉宾隐私，这份责任在沙龙这边。

浏览与报名

  1. 公开到官网 — 计划页勾上「公开到官网」，这场活动才会出现在官网上、才收得到报名。
  2. TA 报名 — 有账号的嘉宾在自己页面上看到这场活动，点「我想参加」。
  3. 你确认 — 报名页的「待确认」里点同意 → 系统自动建记录、发号牌。
拟邀请 ≠ 报名 你从名册点选的人只是「已经叫了，还没答应」。有账号的嘉宾看到「主办方邀请你参加」， TA 按了「我想参加」才算报名。口头答应了的（还没发邀请码的）用「代为确认」由你替 TA 确认。

上载报名清单

报名页和当天签到板上都有两个导入入口：

  • ⬆ 导入名单 / 名单 CSV — Excel 另存为 CSV 直接传。
  • 📷 名单截图 — 群聊截图拍/传上去，AI 自动读出姓名。 它不会抄聊天内容、时间、群名，也不会猜性别 —— 性别显示成灰色的 ♂?，等你点一下确认。

两条路进的都是同一张确认清单，你逐个核对之后才落进名册。

FAQ

11 · 常见问题

忘记密码了

主办台和成员页的登录框下面都有「忘记密码了」。填邮箱 → 收信 → 点信里的链接 → 直接设新密码。 成员忘记密码不用找你，自己就能重设。

为什么总账 / 发布 / 发邀请码点不动

这三样都要登录且账号已通过批准。点右上角头像登录；还在等批准时头像会变成一个等待中的图标。 没登录时其余功能照常可用，只是数据只留在这台设备上。

到处都是「示例」两个字

那是练习用的种子数据，不会上传到云端，也不会算进任何统计。练熟之后到 资产库页面最底下点「清除所有示例数据」，一次清干净。

换了手机 / 换了电脑，东西不见了

没登录的时候数据只在本机。登录并通过批准之后会自动云同步，换设备登录同一个账号就都回来了。

「已结束 · 仍热」是什么

活动结束后 14 天内的那一档 —— 还在跟进复盘、补票据的阶段。过了 14 天自动进「已归档」， 归档的活动打开是只读的。

手机上看不清执行树

手机上树是竖着排开的，功能一样。要看完整的左右两侧 + 时间轴那种视图，用电脑打开。
